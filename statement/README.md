Conditional Statements 
Conditional Statements भनेको कुनै condition को आधारमा कुन code execute गर्ने भनेर decision लिने process हो।

यी notes आफ्नो notebook मा लेख:
- if: Condition true हुँदा code execute गर्छ।
- else: if condition false हुँदा execute गर्छ।
- else if: Multiple conditions check गर्न प्रयोग हुन्छ।
- Nested if: एउटा if भित्र अर्को if।
- switch: एउटै expression को multiple possible values check गर्छ।
- break: switch बाट बाहिर निस्कन्छ।
- default: कुनै case match नभए execute हुन्छ।
- Truthy/Falsy: Condition मा value लाई true वा false को रूपमा evaluate गरिन्छ।
