Concept	Python	JavaScript
Text	str	string
Integer	int	number
Decimal	float	number
Boolean	bool	boolean
Empty value	None	null
Not assigned	No direct equivalent	undefined
List	list	Array
Dictionary	dict	Object
Large integer	int	BigInt


JavaScript Data Types

1. Primitive (7):
   String
   Number

   Undefined

2. Non-Primitive:
   Object
   Array
   Function

Important:
- typeof checks data types.
- typeof null returns "object" (historical bug).
- typeof [] returns "object".
- Array.isArray() checks arrays.
- Primitive assignment copies values.
- Objects are assigned by reference.
