JavaScript Variables

1. var:
   - Function scoped
   - Can be redeclared
   - Can be reassigned

2. let:
   - Block scoped
   - Cannot be redeclared in same scope
   - Can be reassigned

3. const:
   - Block scoped
   - Cannot be redeclared in same scope
   - Cannot be reassigned

Best Practice:
Use const by default.
Use let when reassignment is needed.
Avoid var in modern JavaScript.
